# 🏥 Hospital Analytics Dashboard | Power BI

## 📌 Project Overview
This project focuses on developing an interactive Hospital Analytics Dashboard using Microsoft Power BI to analyze hospital operations, patient information, doctor performance, and financial metrics.

🚧 **Project Status: In Progress**

The dashboard is currently under development, and some sections may be incomplete. However, you can explore the work completed so far, review the available dashboard pages, and see the progress of the project.

## 📊 Dashboard Pages

The dashboard consists of six pages:

1. **Home** — Main landing page for dashboard navigation.
2. **Overview** — High-level summary of key hospital performance indicators.
3. **Patients** — Patient-related data and insights.
4. **Doctors** — Doctor-related information and performance analysis.
5. **Hospital** — Hospital operations and related metrics.
6. **Finance** — Financial performance and hospital revenue analysis.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization and Interactive Reporting

## 📁 Project Files
- **Power BI Dashboard (.pbix):** Interactive report file.
- **Dataset:** Data used for analysis and dashboard development.

## 🎯 Project Objective
To transform hospital-related data into meaningful insights through interactive visualizations, helping users explore patient information, doctor performance, hospital operations, and financial metrics.
